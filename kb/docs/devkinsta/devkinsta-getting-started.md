# DevKinsta - Get Started

**Product:** DevKinsta (local dev tool, not hosting)
**Source:** https://kinsta.com/docs/devkinsta/devkinsta-getting-started/
**Kinsta last updated:** January 25, 2024

---

DevKinsta makes creating and running a WordPress site on your local machine more efficient than manually setting up a local development environment. Get started by downloading and installing DevKinsta for your operating system:

- [Windows](https://kinsta.com/docs/devkinsta/devkinsta-getting-started/installation/#windows)
- [Mac](https://kinsta.com/docs/devkinsta/devkinsta-getting-started/installation/#mac)
- [Linux](https://kinsta.com/docs/devkinsta/devkinsta-getting-started/installation/#linux)

Once DevKinsta is installed, you can create a new WordPress site, import a site from MyKinsta, create a site from a WordPress backup, or create an empty site without WordPress.
