# DevKinsta - Database Management

**Product:** DevKinsta (local dev tool, not hosting)
**Source:** https://kinsta.com/docs/devkinsta/devkinsta-database/
**Kinsta last updated:** January 25, 2024

---

In DevKinsta, when you create a new WordPress site, a database is automatically created. Learn how to manage your site’s database, including using Adminer, accessing the database via terminal/command line, or using tools like TablePlus or Sequel Pro.
