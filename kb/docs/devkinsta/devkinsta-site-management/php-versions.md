# Site Management - PHP Versions

**Product:** DevKinsta (local dev tool, not hosting)
**Source:** https://kinsta.com/docs/devkinsta/devkinsta-site-management/php-versions/
**Kinsta last updated:** January 28, 2026

---

DevKinsta currently supports the following PHP versions:

- 7.2
- 7.3
- 7.4
- 8.0
- 8.1
- 8.2
- 8.3

![Change the PHP version for your site in DevKinsta.](https://kinsta.com/wp-content/uploads/2023/11/devkinsta-php-extensions-1024x761.png)

Change the PHP version for your site in DevKinsta.

## Changing PHP version

Navigate to the **Site configurations** screen (wrench icon) for the site where you want to change the PHP version. Under **PHP Extensions**, click on the **PHP Version** number and choose the version you want from the dropdown list. The site will be inaccessible for a short period of time. Once the update is complete, your environment will be up and running with the new version.
