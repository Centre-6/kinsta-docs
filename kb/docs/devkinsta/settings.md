There are a number of settings available in DevKinsta. This page will walk you through what each of them does.

## Language

DevKinsta is available in a wide variety of languages. Use your operating system’s language (if supported) or select one from the available list.

## Time zone

Time zone settings can be useful for ensuring that your local and remote environments share the same time zone. You can use your operating system’s default or choose from the available time zones.

## Theme

DevKinsta uses dark mode by default but ships with a light mode as well to ensure it fits well with your development environment.

## Automatic updates

You can check versions of DevKinsta manually or enable auto-updates, which always install the newest DevKinsta in the background.

## Site path

Here you can change your site folder location, which is `/Users/user/DevKinsta` by default.

## My account

If you have a MyKinsta account, you can [log in to it](https://kinsta.com/docs/user-settings/logging-in/). If you do not have a Kinsta account, use the **Create MyKinsta account** link to sign up.

## WordPress installation defaults

To ease site creation and standardize it, you can add a default Admin username and password. If given, these will auto-fill details in newly created sites.
