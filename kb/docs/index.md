## Getting started

### Create a new site

Use our site creation wizard to install WordPress that’s ready to build a site from scratch or migrate yourself.

[Guide to adding a new site](https://kinsta.com/docs/wordpress-hosting/wordpress-getting-started/new-site/)

### Migrations

All Kinsta plans come with unlimited site migrations, so we move your existing site to Kinsta for you.

[Migrations guide](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/)

### Domains

Step by step instructions for adding and pointing a domain to your site on Kinsta.

[Domains guide](https://kinsta.com/docs/wordpress-hosting/wordpress-domains/wordpress-add-a-domain/)

## Add-ons

[View all add-ons](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/)

### Customize your plan

Add extra storage or WordPress sites to your plan when you only need a little more than your default limits.

[Additional disk space](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#disk-space-add-on)[Additional WordPress sites](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#wordpress-site-add-on)

### Boost your site

Add extra PHP memory to your site, create powerful development environments, or enable Redis for better response times.

[PHP performance](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#php-performance-add-on)[Premium staging environments](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#premium-staging-environments-add-on)[Redis caching](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#redis-caching-add-on)

### Additional features

Get all your plugins and themes updated automatically, enable reverse proxy, or move your sites to your own server.

[Automatic updates](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#kinsta-automatic-updates)[Reverse proxy](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#reverse-proxy-add-on)[Dedicated server](https://kinsta.com/docs/wordpress-hosting/wordpress-getting-started/dedicated-server/)

### Backups

Beyond daily backups included with all Kinsta plans you can enable 6-hours and hourly backups, and upload backups to a remote server.

[Hourly backups](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#hourly-backups-add-on)[External backups](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#external-backups-add-on)

## Development tools

### Staging environments

All sites come with a free staging environment for testing new WordPress versions, plugins, code, and general development work.

[Guide to using environments](https://kinsta.com/docs/wordpress-hosting/staging-environment/)

### Kinsta API

You can use Kinsta’s REST API to access and interact with your Kinsta projects to retrieve data, perform actions, and automate tasks without using the MyKinsta dashboard.

[API guide](https://kinsta.com/docs/kinsta-api/)

### DevKinsta

With DevKinsta you can design and develop your WordPress sites on your local machine and when you’re ready to go live you can push your site directly to Kinsta.

[DevKinsta guide](https://kinsta.com/docs/devkinsta/)

### Database management

Manage your site’s MySQL database right from the MyKinsta UI. Run queries, view and edit data, add records and tables, and more.

[Database manager guide](https://kinsta.com/docs/wordpress-hosting/database-management/wordpress-database/)

### SSH access

Included with all plans. Perform administrative tasks, execute commands, use tools like Git, Composer, and WP-CLI.

[SSH guide](https://kinsta.com/docs/wordpress-hosting/connect-to-ssh/)

### Analytics

Monitor performance metrics of your site, troubleshoot with logs and data, and track consumption of your plan resources.

[Analytics guide](https://kinsta.com/docs/wordpress-hosting/wordpress-analytics-mykinsta/)
