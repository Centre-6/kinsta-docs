# Omni-Search

**Section:** User Settings
**Product:** MyKinsta User Settings
**Source:** https://kinsta.com/docs/user-settings/omni-search/
**Kinsta last updated:** 2025-02-05T16:40:21

---

[MyKinsta](https://my.kinsta.com/) includes omni-search functionality that allows you to use commands to navigate the MyKinsta interface. For example, if you want to view the domains for a site when you open MyKinsta, you can use the omni-search to enter a site name followed by domains, and this will open the domains page for that site directly from the dashboard. You can also use it to create new sites, applications, databases, and more. Any action you perform with a click of your mouse can be effortlessly accomplished through the omni-search feature, enabling you to run any process or navigate to any page anywhere in MyKinsta.

You can access the omni-search using the following shortcuts:

- **macOS:** `CMD + K`
- **Windows:** `CTRL + K`
- **Linux:** `CTRL + K`

MyKinsta also includes a global search, which you can access using the **Search** option in the top navigation bar or with the shortcut `CMD + /` (macOS) or `CTRL + /` (Windows/Linux).
