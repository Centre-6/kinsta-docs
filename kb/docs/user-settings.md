# User Settings

**Product:** MyKinsta User Settings
**Source:** https://kinsta.com/docs/user-settings/
**Kinsta last updated:** 2026-04-20T09:38:28

---

When you want to use one of our hosting services, you first need to **Sign up**. You can do this through the [Kinsta website](https://kinsta.com/signup/wp/), or you may have been invited to a company via email and sent a link to join.  
You can choose to use single sign-on (SSO) and sign in via your Git provider, or you can create a MyKinsta account that is not linked to a Git provider; if you choose this option, your Password must contain at least the following:

- 8 characters
- 1 special symbol
- 1 capital letter
- 1 number

Once the account is created, you can add the required WordPress Hosting plan.

You can access your user settings within your **username** and then **User settings**.

![Access your user settings in MyKinsta.](https://kinsta.com/wp-content/uploads/2026/01/wordpress-user-settings.png)

Access your user settings in MyKinsta.

The user settings documentation contains information about the following:

- [Logging In](https://kinsta.com/docs/user-settings/logging-in/) – Find out how to enable single sign-on (SSO), two-factor authentication (2FA), and how to reset your MyKinsta password.
- [Notifications](https://kinsta.com/docs/user-settings/notifications) – How to choose which notifications you want to receive from Kinsta.
- [Omni-Search](https://kinsta.com/docs/user-settings/omni-search/) – Find out how to navigate the MyKinsta user interface using commands.
- [Delete My Kinsta Account](https://kinsta.com/docs/user-settings/delete-account/) – Find out how to completely remove your MyKinsta account.
