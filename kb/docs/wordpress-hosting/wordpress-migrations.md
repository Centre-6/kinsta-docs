# WordPress Hosting - Migrations

**Product:** Managed WordPress Hosting
**Source:** https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/
**Kinsta last updated:** March 23, 2026

---

We offer [unlimited free migrations](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/migrating-to-kinsta/) from all hosting providers for sites using standard WordPress installations. Kinsta customers can have websites migrated directly through [MyKinsta](https://my.kinsta.com/) by either sharing information about their current hosting provider or using a backup file.

If you’re migrating yourself, don’t worry, we’ve still got you covered with in-depth walkthroughs:

- [Migrate with Kinsta](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/migrating-to-kinsta/)
- [Manual Migration](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/wordpress-manual-migration/)
- [Migrate with WordPress Duplicator Plugin](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/migrate-wordpress-duplicator-plugin/)
- [Migrate with Migrate Guru Plugin](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/migrate-guru/)
- [Migrate WordPress.com to WordPress.org](https://kinsta.com/blog/wordpress-com-to-wordpress-org/)
- [Powerful WordPress Migration Plugins](https://kinsta.com/blog/wordpress-migration-plugins/)

Got a question about migrations? Check out our most common migration questions within [Migration FAQs](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/wordpress-migration-faqs/).
