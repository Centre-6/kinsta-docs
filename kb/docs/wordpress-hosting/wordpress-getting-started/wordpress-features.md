# Get Started - Features

**Product:** Managed WordPress Hosting
**Source:** https://kinsta.com/docs/wordpress-hosting/wordpress-getting-started/wordpress-features/
**Kinsta last updated:** March 9, 2026

---

Kinsta’s WordPress Hosting allows you to host your WordPress site on our fast and secure infrastructure with [worldwide CDN](https://kinsta.com/docs/wordpress-hosting/wordpress-cdn/kinsta-cdn/), [edge-caching](https://kinsta.com/docs/wordpress-hosting/caching/edge-caching/), and the choice to host on one of [30 data centers](https://kinsta.com/docs/service-information/data-center-locations/). You can [choose the plan](https://kinsta.com/pricing/) that best suits your site, from Single-site, Multiple-site, or Agency plans to your own custom solution.

WordPress Hosting includes the following features:

- **Unlimited free migrations**: You can [migrate a site](https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/migrating-to-kinsta/) from any hosting provider that uses a standard WordPress installation directly through [MyKinsta](https://my.kinsta.com/) by sharing information about your current hosting provider or using a backup file.
- **Kinsta CDN**: Powered by Cloudflare, [Kinsta’s CDN](https://kinsta.com/docs/wordpress-hosting/wordpress-cdn/kinsta-cdn/) is free for all sites and enabled by default. It provides HTTP/3 support, primary domain support, and image optimization.
- **Edge caching**: Free for all Kinsta’s WordPress Hosting plans with no need to install any additional plugins. [Kinsta’s Edge caching](https://kinsta.com/docs/wordpress-hosting/caching/edge-caching/) distributes pages cached in your site’s local data center to Cloudflare’s global network of 300+ data centers. This means when visitors load your website in their browser; cached responses are delivered from the location closest to them, making it faster with fewer server requests.
- **Kinsta’s Application Performance Monitoring (APM) Tool**: Included in all Kinsta’s WordPress Hosting plans for free without installing additional plugins. [Kinsta’s APM Tool](https://kinsta.com/docs/wordpress-hosting/wordpress-monitoring/apm-tool/) captures timestamped information about your WordPress site’s PHP processes, MySQL database queries, external HTTP calls, and more. With the APM data, you can troubleshoot specific slow page loads to identify PHP issues on your site.
- **Automatic backups**: We automatically create daily [backups](https://kinsta.com/docs/wordpress-hosting/wordpress-backups/) of your site as well as system-generated backups for certain events for all sites on your account.
- **STFP and SSH protocols**: SFTP and SSH access are included in all WordPress Hosting plans. Securely connect to your website’s files with [SFTP](https://kinsta.com/docs/wordpress-hosting/connecting-with-sftp/) or use [SSH](https://kinsta.com/docs/wordpress-hosting/connect-to-ssh/) to log into a command prompt, perform common sysadmin tasks, and execute commands on the server.
- **Site management tools**: Use Kinsta’s [Tools](https://kinsta.com/docs/wordpress-hosting/mykinsta-tools/) to clear your site’s cache, enable debug mode, do a search and replace on your site’s content, set up geolocation, change your PHP version, and more, all from one place.
- **Staging environments**: Test new versions of your website or code changes with Kinsta’s free WordPress [staging environment](https://kinsta.com/docs/wordpress-hosting/staging-environment/), which is completely separate from the live production site.
- **Unlimited users**: You can invite as many [users](https://kinsta.com/docs/company-settings/user-management/) as required to your company or site with different levels of access, depending on what their role is.
- **Analytics**: Kinsta’s [Analytics](https://kinsta.com/docs/wordpress-hosting/wordpress-analytics-mykinsta/) provides you with in-depth information about your resource usage, CDN usage, website performance, response stats, visitor insights, and more.
- **Vulnerability detection and automatic updates for your plugins and themes**: MyKinsta scans each plugin and theme daily to identify [security vulnerabilities](https://kinsta.com/docs/wordpress-hosting/wordpress-plugins-themes/#plugin-and-theme-vulnerabilities). You can also enable [Kinsta’s automatic updates](https://kinsta.com/docs/wordpress-hosting/wordpress-plugins-themes/wordpress-plugins-themes-automatic-updates/) for your plugins and themes for just $3 per environment per month, ensuring you stay protected against vulnerabilities without any extra effort.
- **PHP performance:** In MyKinsta, you can quickly diagnose PHP performance issues and optimize your site’s performance by adjusting memory limits and thread allocation to better suit your needs.
