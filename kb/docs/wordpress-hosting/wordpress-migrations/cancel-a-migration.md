# Migrations - Cancel a Migration Request

**Product:** Managed WordPress Hosting
**Source:** https://kinsta.com/docs/wordpress-hosting/wordpress-migrations/cancel-a-migration/
**Kinsta last updated:** April 20, 2026

---

If you need to cancel a migration before it starts, you can do so from the **Sites** page in MyKinsta. Log in to [MyKinsta](https://my.kinsta.com/), navigate to **Sites** > **Migrations**, click on the kebab (three-dot) menu, and select **Cancel migration**. You cannot cancel a migration once it is in progress. If you need to do so, [contact our Support Team](https://kinsta.com/docs/support/contact-support/).

![Cancel a site migration in MyKinsta.](https://kinsta.com/wp-content/uploads/2026/01/wordpress-cancel-migration.png)

Cancel a site migration in MyKinsta.

In the modal/pop-up that appears, click **Cancel migration** to acknowledge that canceling this migration will revert any previous steps. If you want to resume the migration after canceling, you’ll need to start a new migration request from the beginning.

[![Confirm canceling a site migration in MyKinsta.](https://kinsta.com/wp-content/uploads/2023/11/wordpress-cancel-migration-confirm-1024x322.png)](https://kinsta.com/wp-content/uploads/2023/11/wordpress-cancel-migration-confirm.png)

Confirm canceling a site migration in MyKinsta.

A notification will appear in the upper right corner, letting you know the migration has been canceled. The canceled migration will no longer be shown in the **Migrations** section of the **Sites** page.
