# PHP Modules

**Section:** WordPress Hosting > PHP
**Product:** Managed WordPress Hosting
**Source:** https://kinsta.com/docs/wordpress-hosting/php/wordpress-php-modules/
**Kinsta last updated:** 2026-05-05T09:59:12

---

The following PHP modules are installed on your WordPress site on Kinsta by default:

- bcmath
- bz2
- calendar
- Core
- ctype
- curl
- date
- dom
- exif
- FFI
- fileinfo
- filter
- ftp
- gd
- gettext
- hash
- iconv
- igbinary
- imagick
- imap
- intl
- json
- libxml
- mbstring
- mysqli
- mysqlnd
- openssl
- pcntl
- pcre
- PDO
- pdo_mysql
- Phar
- posix
- readline
- redis
- Reflection
- session
- shmop
- SimpleXML
- soap
- sockets
- sodium
- SPL
- standard
- sysvmsg
- sysvsem
- sysvshm
- tokenizer
- xml
- xmlreader
- xmlwriter
- xsl
- Zend OPcache
- zip zlib

[ionCube](https://kinsta.com/docs/wordpress-hosting/mykinsta-tools/#ioncube-loader) is not installed by default, but can be enabled within [MyKinsta](https://my.kinsta.com/) > **WordPress Sites** > ***sitename*** > **Tools** > **ionCube Loader** > **Enable**.

If you have questions about a specific PHP module not included in the list above, contact [Kinsta’s Support Team](https://kinsta.com/docs/support/contact-support/).
