# Find all your WordPress caching tools together in MyKinsta

**Product:** Changelog
**Source:** https://kinsta.com/changelog/mykinsta-navigation-caching/
**Kinsta last updated:** 2024-10-23T14:19:30

---

Various kinds of caching are essential to speeding up a WordPress site, and Kinsta provides all the tools you need to take advantage of those technologies. But, we admit, the [MyKinsta dashboard](https://kinsta.com/mykinsta/) didn’t have all those tools in the same box.

That has changed.

An update to navigation in MyKinsta puts all things related to caching under a single main menu entry labeled (you guessed it) **Caching**. Under that are grouped the tools to manage:

- [Edge Caching](https://kinsta.com/blog/edge-caching-wordpress/)
- [Kinsta CDN](https://kinsta.com/docs/wordpress-hosting/wordpress-cdn/kinsta-cdn/) (the content distribution network)
- [Server caching](https://kinsta.com/docs/wordpress-hosting/caching/site-caching/)
- [Redis cache](https://kinsta.com/docs/wordpress-hosting/caching/redis-cache/)

You can reach that menu by navigating to one of your WordPress sites in MyKinsta and then selecting **Caching** in the left-hand menu:

![Screenshot showing cache-related tools within the MyKinsta dashboard.](https://kinsta.com/wp-content/uploads/2024/07/mykinsta-navigation-caching-menu.png)

Caching tools grouped under the new **Caching** menu item.

Previously, you would have to dig through different menu items for Edge Caching and CDN, while server caching and the Redis add-on were managed through entries in the **Tools** section. Now, it takes less time to reach the tools you need to make your WordPress site faster.

## Take control of cache with Kinsta

Kinsta customers can enable and disable Edge Caching and CDN within the MyKinsta dashboard and clear those caches — as well as the server cache and Redis cache — using the same interface. However, Kinsta offers even more options for managing important tools to [speed up WordPress](https://kinsta.com/ebooks/wordpress/speed-up-wordpress/).

The [Kinsta MU (Must Use) plugin](https://kinsta.com/docs/wordpress-hosting/kinsta-mu-plugin/#kinsta-mu-plugin-settings) offers cache management within the [WordPress admin dashboard](https://kinsta.com/blog/wordpress-admin/). That means members of a publishing team who might not have access to MyKinsta can clear server-side caches, CDN, and edge caches within WordPress.

In addition, the [Kinsta API](https://api-docs.kinsta.com/) is available for those who want to create their own [tools for site maintenance](https://kinsta.com/blog/schedule-tasks-kinsta-api/), including clearing caches.

If you’re not already a Kinsta customer and want to take advantage of these powerful tools for your WordPress site, [find a hosting plan](https://kinsta.com/pricing/) that’s right for you.
