# New Backup Features

**Product:** Changelog
**Source:** https://kinsta.com/changelog/new-backup-features/
**Kinsta last updated:** 2026-09-16T09:36:53

---

We’re announcing an awesome feature for our [Google Cloud Plan](https://kinsta.com/blog/cloud-platform-for-developers/) customers. You can now list your site’s internal backups via the My Kinsta dashboard. One backup is created daily and you can create backups manually – it only takes a few seconds, check it out.

Note that backups can not be downloaded but the last 14 backups (manual and automatic included) are available for restoration. If you’d like to restore a backup simply click the restore button. A new backup will be created before the site is fully restored to make sure you can undo it if needed. Take a look at our [Knowledgebase article](https://kinsta.com/docs/wordpress-hosting/wordpress-backups/#wordpress-backups) for more info or check it out yourself on [MyKinsta](https://my.kinsta.com)
