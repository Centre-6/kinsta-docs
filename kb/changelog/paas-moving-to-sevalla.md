Over the past few years, Kinsta expanded beyond managed WordPress hosting to support applications, databases, and static sites. As these services evolved, it became clear that they benefit from a dedicated platform built specifically for modern, cloud-native workloads.

Starting **February 2, 2026**, application hosting, database hosting, static site hosting and object storage are managed through [Sevalla](https://sevalla.com/), Kinsta’s PaaS platform.

This change allows Kinsta to focus fully on WordPress hosting, while Sevalla continues to evolve as a dedicated home for app, database, static site and other new workloads.

## What’s changing

Applications, databases, and static sites are no longer managed from the MyKinsta dashboard. Instead, these services are now managed in the [Sevalla dashboard](https://app.sevalla.com/), which is where new platform-specific features and capabilities [continue to be added](https://sevalla.com/changelog/).

![Sevalla application overview page.](https://kinsta.com/wp-content/uploads/2026/01/sevalla-application-overview-page.png)

Sevalla application overview page.

This transition does not affect your existing applications, databases, or static sites. Your data, configurations, and runtime settings remain unchanged, and all services continue running without interruption.

Also, if your company already has a payment method set in MyKinsta, it is automatically available in Sevalla. All your projects continue under the same company, pricing, and invoicing setup, just managed through the Sevalla dashboard instead of MyKinsta.

You can access Sevalla using your existing MyKinsta credentials. A direct link to the Sevalla dashboard is also available in MyKinsta for one-click access.

![MyKinsta dashboard showing a quick link to Sevalla.](https://kinsta.com/wp-content/uploads/2026/01/mykinsta-dashboard-sevalla-quick-link.png)

MyKinsta dashboard showing a quick link to Sevalla.

For detailed information about billing, invoicing, APIs, and other questions, see the [Sevalla migration FAQs](https://kinsta.com/docs/service-information/sevalla-overview/#sevalla-migration-faqs).

## Why we’re making this change

Sevalla was created to support a broader Platform-as-a-Service vision that goes beyond WordPress and provides developers with a flexible, scalable environment for running modern workloads.

By separating these services into Sevalla:

- PaaS users get a dedicated dashboard designed specifically for apps, databases, and static sites
- New Sevalla-only features can be delivered faster, including templates, object storage, and deeper analytics
- MyKinsta becomes simpler and more focused for the WordPress CMS

Both platforms continue to be powered by the same infrastructure and engineering expertise behind Kinsta.

## What this means for WordPress hosting

Nothing changes for WordPress hosting customers.

Kinsta remains fully focused on [managed hosting for WordPress](https://kinsta.com/wordpress-hosting/), and you can continue managing your WordPress sites in MyKinsta just as before, with improved navigation.

![MyKinsta dashboard displaying an overview of sites, usage, and account activity.](https://kinsta.com/wp-content/uploads/2026/01/mykinsta-dashboard.png)

MyKinsta dashboard.

## Getting started with Sevalla

If you’re already running applications, databases, or static sites, you can access Sevalla directly from MyKinsta using the provided link with no additional signup required.

If you’re new to Sevalla, learn more about the platform and its features at [sevalla.com](http://sevalla.com), or get started with the [Sevalla documentation](https://docs.sevalla.com/).
