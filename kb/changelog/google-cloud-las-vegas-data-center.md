# Las Vegas Data Center is Now Available

**Product:** Changelog
**Source:** https://kinsta.com/changelog/google-cloud-las-vegas-data-center/
**Kinsta last updated:** 2026-09-16T09:48:35

---

Kinsta is [powered by Google Cloud Platform](https://kinsta.com/blog/cloud-platform-for-developers/)’s multi-regional deployment mode that allows you to place your websites in the closest geographical location to your visitors based on the data centers available. This ensures low latency and blazing fast load times.

Starting today, we’re excited to announce that a new addition entered the [Google Data Center locations list](https://kinsta.com/docs/service-information/data-center-locations/): **Las Vegas, USA.**

This new data center is **already available** **to all Kinsta users**, on all plans.

Here’s how to select it.

Right from within the [MyKinsta dashboard](https://my.kinsta.com/), you can now pick “Las Vegas” as your preferred option when adding a new site.

[![Las Vegas data center is now available.](https://kinsta.com/wp-content/uploads/2020/04/kinsta-las-vegas-datacenter.jpg)](https://kinsta.com/wp-content/uploads/2020/04/kinsta-las-vegas-datacenter.jpg)

Las Vegas data center is now available.

Kinsta now has a total of 30 data center locations you can choose from.

See our knowledge base article on [Google Cloud Platform locations](https://kinsta.com/docs/service-information/data-center-locations/) for more information and questions about moving an existing site.

Have no idea how to choose the best location for your site? Check out [this quick tutorial](https://kinsta.com/docs/service-information/data-center-locations/).
