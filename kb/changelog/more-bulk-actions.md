We’ve made more tools available to customers who manage multiple websites by adding four more add-ons to MyKinsta’s “bulk actions” menu.

In fact, there are now so many Kinsta features you can apply across multiple sites that we’ve redesigned the **Actions** menu to fit everything in.

## The updated Actions menu

The **Actions** menu appears near the top of the **Sites** page in MyKinsta when you select a checkbox next to one or more environment names in the sites list. To keep the menu manageable, we’ve grouped some feature sets into sub-menus for:

- Caching
- Bot protection
- Plugins and themes
- PHP settings
- Backups

Exporting site details to CSV and changing environment labels are the tools that round out the top level of the menu.

## New capabilities for bulk actions

Before, you could change the version of PHP behind multiple websites simultaneously. We’ve added [PHP performance](https://kinsta.com/add-ons/php-performance/) to the **Actions** menu so that you can begin there to choose the optimum combination of server memory and PHP threads for one or more sites:

![A screenshot of the Sites page in MyKinsta with the Actions menu highlighting PHP settings options.](https://kinsta.com/wp-content/uploads/2026/10/mykinsta-sites-actions-change-php-performance.png)

Accessing the PHP performance option in the site Actions menu.

[Backups](https://kinsta.com/blog/kinsta-backup-features/) bring a new category to the **Actions** menu, and you can now start here to configure hourly (every hour or every six hours) and external backups for selected sites:

![A screenshot of the Sites page in MyKinsta with the Actions menu highlighting backup options.](https://kinsta.com/wp-content/uploads/2026/10/mykinsta-sites-actions-change-backups.png)

Accessing the hourly and external backup options in the site Actions menu.

Finally, we’ve added the ability to add or remove [Redis caching](https://kinsta.com/docs/wordpress-hosting/caching/redis-cache/#add-redis-kinsta) via the **Actions** menu:

![A screenshot of the Sites page in MyKinsta with the Actions menu highlighting caching options.](https://kinsta.com/wp-content/uploads/2026/10/mykinsta-sites-actions-change-redis-caching.png)

Accessing the Redis caching option in the site Actions menu.

Some tools and add-ons available through the **Actions** menu trigger additional fees when you add them. You will always have an opportunity to review those costs before confirming your selections.

## More coming

We haven’t got all of Kinsta’s advanced features into our bulk actions menu, but we’re working on it! Check out our [Kinsta add-ons overview](https://kinsta.com/add-ons/) to see what else is available to supercharge your website.
