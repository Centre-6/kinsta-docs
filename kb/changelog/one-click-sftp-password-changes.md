# One-Click SFTP Password Changes

**Product:** Changelog
**Source:** https://kinsta.com/changelog/one-click-sftp-password-changes/
**Kinsta last updated:** 2026-09-16T09:35:33

---

Today we’re pushing out an important security feature: One-click SFTP password changes. Our system auto-generates highly secure passwords and updates the system instantly. The old password will cease to work at once and the new one will take its place. Visit the [help article](https://kinsta.com/docs/wordpress-hosting/connecting-with-sftp/) for more information on how to change your SFTP password.
