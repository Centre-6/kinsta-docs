Here at Kinsta, we are always pushing out continuous improvements to our world-class WordPress hosting platform. In this feature update, we’ll cover a variety of recent changes to MyKinsta including a redesigned user settings page, an updated caching tool, and more.

## Enable and Disabling Site Cache on Staging

By default, [page caching](https://kinsta.com/blog/wordpress-cache/) is disabled on Kinsta staging environments. This allows you to develop your site in an efficient manner without having to worry about cached content. In certain situations, you may want to enable page caching to simulate a live environment.

[![Enable cache on a staging environment.](https://kinsta.com/wp-content/uploads/2020/03/kinsta-staging-environment-enable-cache-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-staging-environment-enable-cache-1.jpg)

Enable cache on a staging environment.

Previously, enabling caching on a staging environment required the assistance of our support team. Now, the “Site Cache” tool in the MyKinsta dashboard has been updated with a new “Enable Cache” button, which allows you to enable caching on staging environments.

## IP Autofill in KinstaDNS

In KinstaDNS, a search-enabled dropdown menu has been added to the “IPv4 Address” field. This new feature allows you to quickly find the correct IPv4 address for your Kinsta site when [adding your domain’s A Record](https://kinsta.com/docs/wordpress-hosting/wordpress-domains/dns/).

[![The new IPv4 address search and autofill functionality makes it easy to find your site's IP address.](https://kinsta.com/wp-content/uploads/2020/03/kinstadns-ipv4-address-dropdown-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinstadns-ipv4-address-dropdown-1.jpg)

Search for your site’s IP address in KinstaDNS.

## Revamped User Settings Page

The “User Settings” page in the MyKinsta dashboard has been revamped. The redesigned page has three tabs – ”My Account”, “Access”, and “Notifications”.

### 1. My Account

The “My Account” page is where you can access general settings such as email, password, [two-factor authentication](https://kinsta.com/changelog/two-factor-authentication-2fa-mykinsta/), and SSH keys.

[![The ](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-my-account-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-my-account-1.jpg)

The “My Account” page in MyKinsta.

### 2. Access

The “Access” page is where you can create a new company and manage the settings for your existing companies.

[![The ](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-access-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-access-1.jpg)

The “Access” page in MyKinsta.

### 3. Notifications

The “Notifications” page is where you can [enable email alerts for overages and invoices](https://kinsta.com/changelog/mykinsta-notification-center-kinsta-invoices/), subscribe to Kinsta’s newsletter, and sign up for our “Beta Crew” to help us test upcoming features before they are released to the general public.

[![The ](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-notifications-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-user-settings-notifications-1.jpg)

The “Notifications” page in MyKinsta.

The category filter for the MyKinsta activity log.

## Miscellaneous Improvements and Changes

Below are a few additional improvements and changes we’ve made over the past couple of weeks.

### Site Names in Vulnerability Emails

WordPress vulnerability notification emails now include the site names of the affected sites. This new feature makes it easier to identify and fix vulnerable sites.

[![Vulnerability emails showing site names](https://kinsta.com/wp-content/uploads/2020/03/affected_sites_by_vulnerable_plugins.jpg)](https://kinsta.com/wp-content/uploads/2020/03/affected_sites_by_vulnerable_plugins-1.jpg)

Vulnerability emails now contain site names.

### New Redirects UI

The redirects tool’s user interface has been overhauled with a new design that makes it easier to manage redirects for your websites.

[![The new redirects tool in the MyKinsta dashboard.](https://kinsta.com/wp-content/uploads/2020/03/kinsta-new-redirects-tool-ui-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-new-redirects-tool-ui-1.jpg)

The new redirects tool in the MyKinsta dashboard.

### Kinsta Go-Live Checklist on Site Creation

When a new Kinsta user creates a site for the first time, MyKinsta will automatically show our [go-live checklist](https://kinsta.com/docs/wordpress-hosting/wordpress-getting-started/go-live-checklist/) in the sidebar. These tips are designed to help familiarize a new user with a few of the key features in the [MyKinsta dashboard](https://kinsta.com/mykinsta/).

[![Be sure to read through Kinsta's go-live checklist during site creation.](https://kinsta.com/wp-content/uploads/2020/03/mykinsta-site-creation-go-live-checklist-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/mykinsta-site-creation-go-live-checklist-1.jpg)

Kinsta’s go-live checklist during site creation.

### Site Name and Domain Search

The MyKinsta search box now supports site name and domain search. If you manage multiple companies and sites, this new feature helps you find what you need quickly just by typing a site or domain in the search box.

[![Search by site name and domain name in MyKinsta.](https://kinsta.com/wp-content/uploads/2020/03/kinsta-site-name-domain-name-search-1.jpg)](https://kinsta.com/wp-content/uploads/2020/03/kinsta-site-name-domain-name-search-1.jpg)

Search by site name and domain name in MyKinsta.
