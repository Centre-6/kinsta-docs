New navigation features are making it easier to get where you need to go within the [MyKinsta dashboard](https://kinsta.com/mykinsta/).

The updated navigation adds a breadcrumb path to MyKinsta’s top-of-page menu and a new **Jump to or search** pop-up dialog that can help you quickly reach important assets.

## MyKinsta breadcrumb menu

The new breadcrumb menu is straightforward, recording the path to your current location within the MyKinsta dashboard:

![Screenshot showing a breadcrumb path to a website in MyKinsta's top men.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-breadcrumbs.png)

Breadcrumb path to the Live environment for a WordPress project named “Paris Site.”

![Screenshot showing a breadcrumb path to an application in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-breadcrumbs-applications.png)

Breadcrumb path to an application named “flask_demo.”

Each breadcrumb entry is clickable so that you can quickly move back up the path.

## MyKinsta “Jump to or search”

Launch the new **Jump to or search** dialog by clicking on the top menu’s search field or by pressing `CMD + /` or `CTL + /` on the keyboard.

No matter where you are within the dashboard, the **Jump to or search** dialog will always provide direct access to your WordPress sites and hosted applications, databases, and static sites:

![Screenshot showing the Jump to or search dialog in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-dialog.png)

A typical display within the **Jump to or search** dialog.

If you have navigated to a WordPress site within the dashboard, the list of assets in the dialog will begin with the website’s environments. You will also see this view if you click on the current WordPress environment label in the breadcrumb menu:

![Screenshot showing a WordPress site's environments listed in the Jump to or search dialog.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-environments.png)

Environments for a WordPress site shown in the **Jump to or search** dialog.

When you invoke **Jump to or search**, the view within the dialog will span any companies to which you have access. This is also where you can jump between companies:

![Screenshot showing companies listed in he Jump to or search dialog in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-companies.png)

You can jump between company accounts by selecting a company name.

The “search” component of **Jump to or search** allows you to filter entries in the list of assets as soon as you begin typing:

![Screenshot showing the search filter within the Jump to or search dialog in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/05/mykinsta-jump-to-or-search-filter.png)

Using the search filter within the **Jump to or search** dialog.

We hope these new features will help you get work done in MyKinsta faster than ever!
