# Implementing the New wp_get_environment_type() Function at Kinsta

**Product:** Changelog
**Source:** https://kinsta.com/changelog/wp_get_environment_type-function/
**Kinsta last updated:** 2021-01-18T16:15:09

---

With the latest WordPress releases always come new interesting features.

That’s what happened with [WordPress 5.5](https://kinsta.com/blog/wordpress-5-5/) which introduced the `wp_get_environment_type()` function to retrieve a site’s current environment type and, in short, provide a more granular control for handling specific functionality between production, development, and staging sites.

As requested of hosting companies, we’re happy to share with you that Kinsta has added support for this new standardized approach.

Starting today, all Kinsta customers are able to take full advantage of the `wp_get_environment_type()` function and `WP_ENVIRONMENT_TYPE` constant when working on our [staging](https://kinsta.com/docs/wordpress-hosting/staging-environment/) and [live](https://kinsta.com/docs/wordpress-hosting/staging-environment/#push-staging-to-live-1) environments.

To stay up to date with future updates, don’t forget to [subscribe to our newsletter](https://kinsta.com/wordpress-newsletter/)!
