# Kinsta’s PHP Performance add-on is now available to everyone

**Product:** Changelog
**Source:** https://kinsta.com/changelog/php-performance-update/
**Kinsta last updated:** 2026-09-16T09:33:20

---

All customers can now optimize a WordPress site’s PHP threads and memory limits within the MyKinsta dashboard.

When we [launched the PHP Performance add-on](https://kinsta.com/changelog/php-performance/) at the end of 2024, it was available to most customers, but not for Agency and Enterprise accounts, or for many with custom hosting plans. We’ve since completed the transition for everyone!

## Optimizing PHP threads and memory

The [PHP Performance add-on](https://kinsta.com/docs/wordpress-hosting/wordpress-add-ons/#php-performance-add-on) helps WordPress managers exactly balance available memory with the number of [PHP threads](https://kinsta.com/changelog/workers-now-threads/) their sites require to function at their best. With the self-serve add-on, customers can easily assign the optimum amount of memory to each thread while adjusting the total amount of memory needed to accommodate those requirements.

The add-on — which you can find in MyKinsta by navigating to **WordPress sites** > ***sitename*** > **Info** > **PHP Performance** — can be applied to live sites and [Premium Staging](https://kinsta.com/wordpress-hosting/staging/) environments.

![Screenshot showing the PHP Performance Add-on tool in the MyKinsta dashboard.](https://kinsta.com/wp-content/uploads/2024/12/php-performance-allocation.png)

Juggling the total PHP memory pool with individual threads in MyKinsta.

You can adjust the number of threads allotted to a site for free at any time, but charges are applied when increasing the total memory pool.

When using the add-on, only Company Owners and Company Administrators can adjust the total memory pool. Company Developers and Service-Level Administrators can adjust the PHP threads and memory per thread, but they cannot change the total memory pool.
