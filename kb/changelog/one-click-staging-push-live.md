# One-Click Staging Push To Live

**Product:** Changelog
**Source:** https://kinsta.com/changelog/one-click-staging-push-live/
**Kinsta last updated:** 2023-05-01T11:34:42

---

We’re super happy to announce an amazing new feature for our Google Cloud plan customers today: Push to live. Each of your sites has a staging environment you can use to test new plugins and new code. Once you’re happy with your tests you can now click a button to push all these changes to your live environment automatically.

Please read our [knowledgebase article](https://kinsta.com/docs/wordpress-hosting/staging-environment/#push-staging-to-live-1) for all the information about push to live, and happy developing!
