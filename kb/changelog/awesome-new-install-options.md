# Awesome New Install Options

**Product:** Changelog
**Source:** https://kinsta.com/changelog/awesome-new-install-options/
**Kinsta last updated:** 2026-09-16T09:58:26

---

Today we’re announcing no less than three new features related to our [site installation](https://kinsta.com/docs/wordpress-hosting/wordpress-getting-started/new-site/) feature. You can now fine-tune your site installation using the following settings:

- Select the language for your WordPress installation
- Create a multisite installation automatically (subdomain or subdirectory)
- Install WooCommerce automatically

We’re aiming to give you much more flexibility with your websites and we want to decrease the time you need to spend on website creation and management. These three settings are just the start of our automation efforts, stay tuned for more!
