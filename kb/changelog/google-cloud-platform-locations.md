# All 11 Google Cloud Platform Locations Now Available

**Product:** Changelog
**Source:** https://kinsta.com/changelog/google-cloud-platform-locations/
**Kinsta last updated:** 2026-09-16T09:47:33

---

We’ve been busy behind the scenes and are excited to announce that all 11 Google Cloud Platform data center locations are now available! This infrastructure change allows you to even more strategically position your WordPress sites closer to your visitors and customers. This helps to decrease latency, [TTFB](https://kinsta.com/blog/ttfb/), and ensure faster page load times. Below is a list of our current and new locations:

- Council Bluffs, Iowa, USA (current)
- St. Ghislain, Belgium (current)
- Changhua County, Taiwan (current)
- Sydney, Australia **(new)**
- The Dalles, Oregon, USA **(new)**
- Ashburn, Virginia, USA **(new)**
- Moncks Corner, South Carolina, USA **(new)**
- London, UK **(new)**
- Frankfurt, Germany **(new)**
- Jurong West, Singapore **(new)**
- Tokyo, Japan **(new)**

These locations are now available from within the [MyKinsta](https://my.kinsta.com/) dashboard when you go to add a new site.

![Google Cloud Platform server locations](https://kinsta.com/wp-content/uploads/2017/08/google-cloud-server-locations-1.png)

Google Cloud Platform server locations

See our knowledge base article on [Google Cloud Platform locations](https://kinsta.com/docs/service-information/data-center-locations/) for more information and questions about moving an existing site.
