Updated
:   July 10, 2023

Today we’ve updated all our Google Cloud servers to use the latest Ubuntu 16.04 “Xenial Xerus” to further secure and optimize our network. This new update features the new long-term supported Linux 4.4 kernel, Python 3, OpenSSH 7.2p2 and Apt 1.2. Read all about the new version on the [release notes](https://wiki.ubuntu.com/XenialXerus/ReleaseNotes#New_features_in_16.04_LTS) page.
