![Illustration representing the interface for the Reset WordPress Site function in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/03/reset-wordpress-site-mykinsta-1024x536.png)

A **Reset WordPress Site** option available now in your MyKinsta dashboard makes it easy to execute a web development do-over, perhaps undoing changes that *seemed* like a good idea at the time.

Company Owners and Company Administrators (the same [user roles](https://kinsta.com/docs/company-settings/user-management/) that have access to delete sites) can execute a reset that removes and reinstalls all WordPress files and the database but preserves any [domain name](https://kinsta.com/docs/wordpress-hosting/wordpress-domains/) configurations, [backups](https://docs.sevalla.com/databases/backups), and [activity logs](https://kinsta.com/docs/wordpress-hosting/wordpress-troubleshooting/view-server-logs/).

Any standard and premium [staging environments](https://kinsta.com/docs/wordpress-hosting/staging-environment/) are also removed.

A reset reinstalls WordPress with the site details selected during the original launch of your site, including its data center and the addition of the [multisite option](https://kinsta.com/wordpress-hosting/multisite/), [Yoast SEO](https://kinsta.com/blog/yoast-seo/), [WooCommerce](https://kinsta.com/topic/woocommerce/), and [Easy Digital Downloads](https://kinsta.com/blog/easy-digital-downloads/).

In addition to preserving your site’s historical backups, a site reset launches one more system backup before deleting the current installation.

## Why reset a site when you can delete it?

The ultimate website do-over begins with the **Delete Site** option in MyKinsta. But a reset provides a clean slate for the WordPress installation without the loss of domain name configurations or historical data in backups and activity logs.

While a reset doesn’t allow you to change the site name displayed in MyKinsta, you can do that separately using the [edit site name tool](https://kinsta.com/docs/wordpress-hosting/site-management/#rename-a-site-in-mykinsta).

## How to reset a WordPress site in MyKinsta

To reset a site, select it in the **WordPress Sites** list and then click on **Info** in the left-hand menu. Scroll down to click the **Reset site** button:

![Screenshot showing the location of the Reset site button among the Info option.](https://kinsta.com/wp-content/uploads/2024/03/reset-site-option-mykinsta-info-menu.png)

The **Reset site** button within the **Info** group of options.

The next dialog asks you to provide a WordPress admin password for the new site. Other site details will reflect the options selected when the site was first created:

![Sreenshot of the Reset site dialog and the WordPress admin password field.](https://kinsta.com/wp-content/uploads/2024/03/reset-site-option-mykinsta-change-admin-password.png)

Entering a WordPress admin password for the new site.

After clicking the **Continue** button, you will be asked to confirm your decision to reset the site by typing the site name and its environment indicator:

![Screenshot showing the confirmation dialog for a WordPress site reset in MyKinsta.](https://kinsta.com/wp-content/uploads/2024/03/reset-site-option-mykinsta-confirmation.png)

Confirming a WordPress site reset.

After confirming the reset, your site will be backed up before WordPress and its database are deleted and reinstalled.

If you change your mind after resetting a site, you can return your WordPress installation to a previous state by [restoring a backup](https://docs.sevalla.com/databases/backups#restore-a-backup).
